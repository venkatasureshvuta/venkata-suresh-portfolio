# Venkata Suresh Vuta — Cloud Engineer Portfolio

## Files
- `index.html` — portfolio page
- `styles.css` — responsive styling
- `script.js` — mobile navigation and contact form mailto behavior

## Publish with GitHub Pages
1. Create a GitHub repository named `venkatasureshvuta.github.io` under `venkatasureshvuta`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub, open Settings → Pages.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Your public site will normally be available at:
   `https://venkatasureshvuta.github.io/`
